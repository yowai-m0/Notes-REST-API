# Notes API

Простой REST API для управления заметками на Go (`net/http`, без сторонних фреймворков).  
Данные хранятся в JSON-файле (`notes.json`), без базы данных. Учебный проект для отработки HTTP, JSON, работы с файлами и конкурентности в Go.

## Возможности

| Метод    | Путь                    | Описание                           |
|----------|-------------------------|------------------------------------|
| `POST`   | `/notes`                | Создать заметку                    |
| `GET`    | `/notes`                | Получить список всех заметок       |
| `GET`    | `/notes?tag=work`       | Получить заметки с указанным тегом |
| `GET`    | `/notes/search?q=text`  | Поиск по заголовку и содержимому   |
| `GET`    | `/notes/{id}`           | Получить заметку по id             |
| `PUT`    | `/notes/{id}`           | Обновить заметку целиком           |
| `DELETE` | `/notes/{id}`           | Удалить заметку                    |

## Структура заметки

```json
{
  "id": 1,
  "title": "Первая заметка",
  "content": "Текст заметки",
  "tags": ["work", "urgent"],
  "created_at": "2026-10-11T14:32:05Z"
}
```

## Валидация

При создании и обновлении заметки проверяется:

- `title` не должен быть пустым

При нарушении сервер отвечает `400 Bad Request`.

## Коды ответов

| Код | Когда возвращается                                         |
|-----|------------------------------------------------------------|
| 200 | Успешное чтение, обновление или удаление                   |
| 201 | Заметка успешно создана                                    |
| 400 | Некорректный JSON, неверный id или не прошла валидация     |
| 404 | Заметка с таким id не найдена                              |
| 405 | Метод не поддерживается для этого пути                     |
| 500 | Ошибка сохранения файла или кодирования JSON               |

## Технологии и приёмы

- `net/http`: маршрутизация с указанием метода прямо в пути (Go 1.22+)
- `encoding/json`: декодирование запросов и кодирование ответов
- `sync.Mutex`: защита общего слайса заметок от гонки данных при параллельных запросах
- `os.ReadFile` / `os.WriteFile`: сохранение заметок в JSON-файл между запусками
- middleware для логирования запросов (метод, путь, время выполнения)
- path-параметры (`{id}`) и query-параметры (`?tag=`, `?q=`)
- корректные HTTP-статусы и обработка ошибок

## Middleware

Все запросы логируются через `logging`. В консоль пишется метод, путь и время выполнения:

```
POST /notes took 1.2ms
GET /notes took 245µs
GET /notes?tag=work took 310µs
GET /notes/search?q=go took 220µs
PUT /notes/1 took 800µs
```

## Запуск

```bash
go run main.go
```

Сервер стартует на `http://localhost:8080`.  
При первом запуске файл `notes.json` создаётся автоматически.

## Примеры запросов

Создать заметку:
```bash
curl -X POST http://localhost:8080/notes -d '{"title":"Work","content":"task 1","tags":["work"]}'
```

Получить все заметки:
```bash
curl http://localhost:8080/notes
```

Фильтр по тегу:
```bash
curl "http://localhost:8080/notes?tag=work"
```

Поиск по заголовку и содержимому:
```bash
curl "http://localhost:8080/notes/search?q=task"
```

Получить заметку по id:
```bash
curl http://localhost:8080/notes/1
```

Обновить заметку:
```bash
curl -X PUT http://localhost:8080/notes/1 -d '{"title":"Updated","content":"new text","tags":["work"]}'
```

Удалить заметку:
```bash
curl -X DELETE http://localhost:8080/notes/1
```

> **Windows / PowerShell:** вместо `curl` используйте `curl.exe` или `Invoke-RestMethod`.
> Пример:
> ```powershell
> Invoke-RestMethod -Uri http://localhost:8080/notes -Method POST -Body '{"title":"Work","content":"task 1","tags":["work"]}' -ContentType "application/json"
> ```

## Требования

Go 1.22 или новее (используется синтаксис маршрутизации с методом и path-параметрами).
